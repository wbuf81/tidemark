# Security

## Reporting a problem

Please use GitHub's private vulnerability reporting: on the repository's Security tab, choose
"Report a vulnerability". Please don't open a public issue for something that could harm users.

Helpful to include: the Tidemark version (Tidemark menu → About), your macOS version, and the
steps to reproduce.

## What counts

Tidemark reads local files (Claude Code sessions, git history) and, only if you turn it on, a
signed-in claude.ai window. Reports about these are especially welcome:

- anything that sends your data off your Mac
- reading or writing files outside Tidemark's folder, Claude Code's settings hooks or the folders you chose
- a way to read the claude.ai sign-in from outside Tidemark's own store
- the install or uninstall steps leaving more than they say

## Supported versions

The latest release. Tidemark is not signed or notarized by Apple (see the README's set-up steps),
so check the `.sha256` file next to each download.

This is a small free project with no deadlines promised, but reports are read and answered.
